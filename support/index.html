Support & FAQ

Answers to common questions. Can't find yours? Open an issue on GitHub.

Getting Started
What is Dojix? ▾
Dojix is a free, open-source trade journal for forex traders on the Mac. Import your trade history and it gives you a journal, a dashboard of more than 60 analytics, and an Edge Report that ranks the sessions, hours, days and pairs that help or hurt you, in dollars. Your trades never leave your Mac.
Is it really free? ▾
Yes. Every feature is available to everyone. Nothing is locked and nothing expires. Dojix is free software under the GNU GPL v3.0, and the full source code is on GitHub. The only possible costs are from optional services you connect with your own key (for example Anthropic for AI recommendations, or a paid live-price plan), which those providers bill to you directly.
How do I install it? ▾
  • Download Dojix-macOS-unsigned.zip from the latest release on GitHub.
  • Unzip it and drag Dojix.app to your Applications folder.
  • The first time, right-click (or Control-click) Dojix.app, choose Open, then click Open again. If there's no Open button, try to open it once, then go to System Settings > Privacy & Security and click Open Anyway.
You can also build Dojix from source with Xcode.
Can I try it before importing my own trades? ▾
Yes. Go to Settings > Data > Load Sample Trades to add 30 fictional trades and explore every screen. Remove Sample Trades takes only those out again. To try an import, drop samples/sample-mt4.csv from the repository (five made-up trades) onto the Import screen.
How do I import my trades? ▾
Dojix imports from:
  • MetaTrader 5 — StrategyAnalytics CSV
  • MetaTrader 4 — trade history CSV
  • cTrader, TradingView, thinkorswim, NinjaTrader — CSV export from each platform
  • OANDA — CSV, or directly through the OANDA API with your own token
  • Interactive Brokers — CSV export
  • Any other platform — any CSV through a column-mapping screen
Drag and drop your file onto the Import screen. Dojix detects the format.
What macOS version do I need? ▾
macOS 14 Sonoma or later.
Is there a Windows version? ▾
A Windows version is coming soon. Today Dojix is a native Mac app.
Importing & Data
What is StrategyAnalytics (SA)? ▾
For MetaTrader 5 history, Dojix reads a 32-column "StrategyAnalytics" CSV format (files named StrategyAnalytics_Results_*.csv) that carries extra fields such as MAE/MFE and R-multiples. The script that writes that format is not part of the repository; any other MT5 CSV export can be imported through the column-mapping screen. Times in StrategyAnalytics files are broker-server time and are currently read as UTC, so hour and session statistics from those files can be shifted by your broker's offset.
Will importing duplicate my trades? ▾
No. Re-importing the same file, or a file that overlaps trades you already have, never creates duplicates.
My CSV won't import. What should I check? ▾
Common fixes:
  • Make sure the file is a .csv file (not .xlsx or .txt)
  • Check that the file has column headers in the first row
  • If your platform isn't detected, use the column-mapping screen to map the required fields and try again
  • OANDA users can use the OANDA API import instead of a CSV
If it still won't work, open an issue on GitHub with a small, made-up file in the same format. Never post real trades, account numbers, broker statements or API keys.
Can I set up auto-import from MT5? ▾
Yes. In Settings, set the path to your MT5 Common Files folder. Dojix watches that folder and imports new StrategyAnalytics exports automatically. On Mac, MT5 runs through Wine, so the folder is typically:
~/Library/Application Support/net.metaquotes.wine.metatrader5/drive_c/Program Files/MetaTrader 5/MQL5/Files/
Where is my data stored? ▾
In ~/Library/Application Support/Dojix/ on your Mac. The journal and your trade screenshots are encrypted on disk with AES-256-GCM, and the decrypted journal exists only in memory while Dojix runs. There is no cloud sync, no telemetry and no server-side copy.
How do I back up my data? ▾
In Settings > Data, use Export Backup. Adding a password is recommended: password-protected backups are encrypted (AES-256-GCM); a backup without a password is not. To restore, use Restore Backup. Every restore is checked before anything in your journal is replaced.
Privacy & Security
Does Dojix send my trade data anywhere? ▾
No. Dojix works fully offline. The only network connections are optional features you turn on with your own keys, plus the public economic calendar:
  • AI recommendations — a summary of your statistics goes to Anthropic, only when you click Run Analysis. Never individual trades, tickets or notes.
  • Live prices — the pairs on your watchlist go to your chosen provider (Twelve Data, Polygon.io or OANDA). MetaTrader 5 prices are read from a local file.
  • OANDA import — your OANDA token and account ID, to fetch your own history.
  • Economic calendar — downloads the public weekly calendar; nothing about you is sent.
There is no telemetry and no automatic update check. See the privacy page for details.
Is my database encrypted? ▾
Yes, always. The journal is encrypted on disk with AES-256-GCM and the key is kept in your macOS Keychain. With App Lock on, the key is sealed with your password, so the journal can't be decrypted without it, even by someone who copies the files.
Can I lock the app with a password? ▾
Yes. Go to Settings > Security and click Enable App Lock (minimum 8 characters). Dojix locks after the idle time you choose (Off, 1, 5, 15, 30 or 60 minutes; default 15) and whenever the Mac sleeps, the screen locks, or you hide or minimize Dojix. Wrong passwords are throttled. There is no password recovery: a forgotten password means erasing the local data and restoring from a backup.
How do I report a security problem? ▾
Please report it privately through the repository's private vulnerability reporting (Security tab > Report a vulnerability), not in a public issue. Include the Dojix version and the steps to reproduce it, with made-up data only.
Features
What analytics does Dojix include? ▾
More than 60, grouped into tabs:
  • Timing — trade calendar, hourly P&L, day-of-week analysis, duration analysis, time heatmap
  • Sessions — session heatmap, R-multiple distribution, session intelligence, sequence analysis, streaks, kill zone optimizer, what-to-cut advisor
  • Pairs — win/loss distribution, pair analytics, lot size analysis, MAE/MFE, directional edge, slippage analysis
  • Risk — risk of ruin, discipline score, Monte Carlo, drawdown recovery, growth projections, position sizing, exit efficiency, commission tracking, net currency exposure
  • Behavioral — trade grades, consistency score, emotional P&L, checklist compliance, improvement tracker, playbook catalog
  • Advanced — news calendar correlation, event impact profiler, benchmark comparison, pair correlation, edge decay, time-to-MFE
Plus the Edge Report and Pulse. An Essential view keeps the dashboard simple. See the Features page for screenshots.
How do the AI recommendations work? ▾
They are optional and off by default. Add your own Anthropic API key in Settings (usage is billed to your Anthropic account), then click Run Analysis in the Edge Report. Dojix sends a summary of your statistics (totals, and P&L and win rate by session, hour, day, pair, bias and volatility), never individual trades or notes, and gets back 3-5 ranked recommendations with dollar estimates.
What live data sources are supported? ▾
Five options for Pulse, all optional:
  • Twelve Data REST (default) — polls every 2 minutes; Twelve Data's free tier allows 800 requests/day
  • Twelve Data WebSocket — real-time streaming, requires a paid Twelve Data plan
  • OANDA Streaming — real-time via the OANDA API, free with an OANDA account
  • Polygon.io WebSocket — real-time streaming, requires a Polygon.io subscription
  • MT5 Direct — reads prices written by a small Expert Advisor (mt5/DojixPriceFeed.mq5 in the repository), no API key needed
Choose your source and enter its key in Settings.
What is the Prop Firm Tracker? ▾
It tracks your account against funded-account rules: account size, profit target, daily loss limit and maximum drawdown. Progress bars show how close you are to each limit so you can protect an evaluation or funded account.
Troubleshooting
macOS says Dojix "can't be opened" or "cannot verify the developer" ▾
That's expected: Dojix is not signed with an Apple Developer ID or notarized. To open it:
  • In Finder, right-click (or Control-click) Dojix.app, choose Open, then click Open in the dialog. You only need to do this once.
  • If there is no Open button, try to open the app once, then go to System Settings > Privacy & Security, scroll to the message about Dojix and click Open Anyway.
Download Dojix only from the GitHub Releases page, and compare the .sha256 file published with each release (shasum -a 256 Dojix-macOS-unsigned.zip), or build it from source.
macOS asks for my login password to use the Keychain ▾
Because the app isn't signed with a developer certificate, macOS may ask the first time a new version reads its Keychain items (your API keys and the database key). Choose Always Allow.
Pulse shows no live prices ▾
Check these:
  • Live prices are optional: make sure a data source is chosen and its API key entered in Settings
  • Make sure you're connected to the internet
  • Twelve Data's free tier allows 800 requests/day; if you've hit the limit, prices resume the next day
  • Forex prices only move while the market is open (Sunday evening to Friday evening, New York time)
I found a bug or have an idea ▾
Please open an issue on GitHub with what you expected, what happened, the steps to reproduce it, and your Dojix version (Dojix > About Dojix). If a file triggers the bug, attach a small fictional version of it.
